# Meal Planner Web App (Capstone Project)

## Overview
This project is a full-stack web application that helps users plan weekly meals and automatically generate grocery lists. Users can select 
dietary preferences and the number of meals they want for the week, and the system generates a meal plan along with a categorized grocery 
list. The goal of the project is to simplify meal planning by automating recipe selection and grocery list organization.

## Technologies
Frontend:
- React
- Vite

Backend:
- Node.js
- Express

API:
- Spoonacular Recipe API

## Running the Project

Start the backend:
cd backend
npm install
npm run dev

Start the frontend:
cd frontend
npm install
npm run dev

Frontend runs on:
http://localhost:5173

Backend runs on:
http://localhost:3000
